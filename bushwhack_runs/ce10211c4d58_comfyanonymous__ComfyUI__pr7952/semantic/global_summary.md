ComfyUI is a modular, graph-based orchestration engine for diffusion model inference, built on PyTorch. It abstracts complex generative AI workflows into reusable nodes that can be programmatically composed, executed, and optimized. The system supports a wide range of model architectures (UNet, DiT, MMDiT, Hunyuan, Flux, etc.), external APIs (Luma, Recraft, BFL, etc.), and deployment scenarios (local GPU, cloud inference, 3D generation). The architecture emphasizes decoupling between runtime infrastructure, model definitions, and high-level workflow logic, enabling extensibility and community-driven node development. The core pipeline flows from model loading → conditioning → sampling → decoding, with strong emphasis on GPU memory management, scheduling, and conditional control mechanisms (ControlNet, CFG). Multiple optimization layers (torch.compile, attention mechanisms, token merging) are available to enhance inference speed and memory efficiency. External service integrations are treated as adapters that plug into the core graph via defined request/response contracts. The system is designed for both programmatic API usage (HTTP, WebSocket) and user-facing node composition, with tests and configuration layers ensuring stability and compatibility.
